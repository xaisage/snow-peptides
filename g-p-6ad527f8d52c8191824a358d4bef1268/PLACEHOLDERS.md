# Platzhalterinventar

Vor jeder Veröffentlichung alle nachfolgenden Inhalte ersetzen, fachlich/rechtlich prüfen und konsistent pflegen. Keine hier aufgeführten Werte stellen reale Produktangaben oder echte Nachweise dar.

| Pfad | Zu ersetzen |
| --- | --- |
| `index.html` | Seitentitel, Meta-Beschreibung |
| `src/data/products.json` | Produktnamen, Kategorien, Preise, Einheiten, Beschreibungen, Labels, Badge |
| `src/data/categories.json` | alle sechs Kategorien |
| `src/data/studies.json` | Studien, Autorenschaft, Journale, DOI, Zusammenfassungen |
| `src/data/articles.json` | sechs Titel, Teaser, Lesezeiten und spätere Quellen |
| `src/data/faq.json` | Fragen und Antworten |
| `src/data/legal.json` | sämtliche Rechts- und Cookie-Texte |
| `src/data/settings.json` | Markenname, Versandgrenze, Alters-Hinweis-Konfiguration |
| `src/data/gauge.json` | Umrechnungswerte, Farbcodes, Prüfvermerk |
| `src/App.tsx` | Shopname, Startseitentexte, Lieferstatus, Produkt-Pflichtangaben, Checkout, Konto-, FAQ-, Newsletter- und Artikelinhalte; Double-Opt-in; Gutschein; Hinweisdialog; Such-/Filtertexte |
| `src/styles.css` | lokal bereitgestellte Schriftarten und finales Markenfarbsystem |
| `DESIGN-NOTES.md` | Platzierungserläuterungen nach Ergänzung weiterer Module |

Neutrale Produktgrafiken in `src/App.tsx` sind illustrative CSS/SVG-nahe Formen und keine Produktfotos. Im Quelltext als Platzhalter markierte Daten dienen ausschließlich dem funktionsfähigen UI-Prototyp.
