# Snow Peptides prototype

Eigenständiger, frameworkfreier Website-Prototyp. Zum lokalen Anzeigen im Ordner `node serve.mjs` starten und `http://127.0.0.1:4174` öffnen.

Warenkorb und Wunschliste werden im Browser lokal gespeichert. Katalogpreise, Produktdokumentation, Kontaktdaten und Rechtstexte sind ausdrücklich Demo-Platzhalter; es gibt keinen echten Checkout.
